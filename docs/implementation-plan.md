# 三个 Windows 桌宠复刻方案与执行计划

用户已授权：直接复刻三个项目，安装本机并验证后，分别上传 GitHub。

目标仓库：2825063921-sketch/SunPet-Windows、ShaolanPet-Windows、FengGe-Desktop-Pet-Windows。每个仓库均可独立构建、安装和运行。

采用 C# / Windows 自带 .NET Framework 4.8 / WPF，无 NuGet、npm、Python 运行依赖。参考 yzh423/SunPET 的 MIT 播放器与随机播放实现，使用 Ganzhe2028 三个原项目的头像、原声、清单与版权声明；SunPet 使用参考项目的 PCM WAV 播放副本。素材权利与代码许可分开说明。

共用代码逐字复制到三个独立仓库，通过 pet.json 区分角色、标题、音频数与精选池。src/Core.cs 负责随机池和纯接话规则；VoicePlayer.cs 管理播放生命周期；Bridge.cs 管理同用户会话的本地接话；PetWindow.cs 管理透明窗口和偏好；Program.cs 验证素材与启动；NativeTests.cs 验证实际音频解码播放。build.ps1 仅用 Windows 自带编译器；install.ps1 安装到当前用户并建立快捷方式。不得修改安全设置或开机启动项。

功能：原始透明头像、点击原声、拖动、字幕与摆动、音量、尺寸、固定/随机播放、音频筛选、暂停联动、停止、退出、保存设置和同角色单实例。薄肌默认8句但完整37句可选；SunPet28句；峰哥11句。联动遵守 薄肌→SunPet→峰哥→SunPet→停止；点击峰哥仅峰哥→SunPet；点击SunPet不触发同伴。回应在前句播放结束后发出，避免叠音。无机身加速度计功能。
